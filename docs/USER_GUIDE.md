# ClipFlow Studio User Guide

## Getting Started

Welcome to ClipFlow Studio! This guide will help you create your first video in minutes.

### Installation

#### Windows
1. Download `ClipFlow-Studio-Setup-1.0.0.exe`
2. Double-click to run installer
3. Follow the installation wizard
4. Launch from Start Menu or Desktop shortcut

#### macOS
1. Download `ClipFlow-Studio-1.0.0-x64.dmg`
2. Open the DMG file
3. Drag ClipFlow Studio to Applications folder
4. Launch from Applications or Spotlight

#### Linux
1. Download `ClipFlow-Studio-1.0.0.AppImage`
2. Make executable: `chmod +x ClipFlow-Studio-1.0.0.AppImage`
3. Run: `./ClipFlow-Studio-1.0.0.AppImage`

#### Web Version
Visit [app.clipflow.studio](https://app.clipflow.studio) - works offline after first load!

When you first launch ClipFlow Studio:

1. **Choose Your Mode**

   - Can be restarted from Settings > Help

3. **Configure Privacy Settings**
   - Local-only mode (default)
   - Optional cloud features for enhanced AI

## Creating Your First Project

### Step 1: New Project
1. Click **"New Project"** on welcome screen
2. Enter a project name
3. Choose aspect ratio:
   - **16:9** - YouTube, standard videos
   - **9:16** - TikTok, Reels, Shorts
   - **1:1** - Instagram square posts
   - **4:5** - Instagram portrait posts

### Step 2: Import Media
1. Drag files into the **Media Panel** (left sidebar)
2. Or click the upload area to browse
3. Supported formats:
   - Video: MP4, MOV, AVI, MKV, WebM
   - Audio: MP3, WAV, OGG, FLAC, AAC
   - Images: JPG, PNG, GIF, WebP

### Step 3: Add to Timeline
1. Click the **▶️ play button** on any media item
2. It automatically adds to the appropriate track
3. Videos go to Video track, audio to Audio track

### Step 4: Trim Your Clips
1. Click on a clip in the timeline
2. Drag the **left edge** to trim the start
3. Drag the **right edge** to trim the end
4. Or use **Split** tool to cut at playhead position

### Step 5: Add Captions
1. Go to **Captions** panel in sidebar
2. Click **"Auto-Generate Captions"**
3. AI will transcribe your video
4. Edit any text by clicking on captions

### Step 6: Export
1. Click **"Export"** button (top right)
2. Choose your platform preset
3. Click **"Export"**
4. Wait for processing to complete
5. File saves to your chosen location

## Advanced Features

### Multi-Track Editing
In Advanced Mode, you have multiple tracks:
- **Video Tracks** - Stack videos, images
- **Audio Tracks** - Layer sounds, music
- **Caption Track** - Subtitles and text overlays
- **Overlay Track** - Graphics and effects

### Keyboard Shortcuts
| Key | Action |
|-----|--------|
| `Space` | Play/Pause |
| `S` | Split clip at playhead |
| `Delete` | Remove selected clip |
| `Ctrl+Z` | Undo |
| `Ctrl+Shift+Z` | Redo |
| `Ctrl+S` | Save project |
| `Ctrl+E` | Export |
| `←` / `→` | Skip 1 second |
| `Shift+←` / `Shift+→` | Skip 10 seconds |
| `+` / `-` | Zoom timeline |

### Using Shortify (AI)

The Shortify feature automatically creates short-form content:

1. Click **"Shortify"** button in toolbar
2. Choose duration: 15s, 30s, or 60s
3. Select style:
   - **Hook & CTA** - Attention-grabbing intro
   - **Best Highlights** - Peak moments
   - **Quick Summary** - Main points condensed
4. Enable options:
   - Auto-captions (recommended)
   - Smart vertical crop
5. Click **"Generate Short"**
6. AI analyzes and creates your short

## Export Guide

### Platform Presets

**YouTube (Long-form)**
- Resolution: 1920x1080
- 30 fps, 8 Mbps
- Best for: Tutorials, vlogs, podcasts

**YouTube Shorts**
- Resolution: 1080x1920
- 30 fps, 6 Mbps
- Best for: Quick tips, reactions

**TikTok**
- Resolution: 1080x1920
- 30 fps, 6 Mbps
- Best for: Trends, entertainment

**Instagram Reels**
- Resolution: 1080x1920
- 30 fps, 6 Mbps
- Best for: Behind-the-scenes, tutorials

**Instagram Feed**
- Resolution: 1080x1080
- 30 fps, 5 Mbps
- Best for: Product shots, announcements

**Twitter/X**
- Resolution: 1920x1080
- 30 fps, 6 Mbps
- Best for: News, commentary

### Export Options
- **Include Audio** - Toggle audio tracks
- **Burn in Captions** - Embed subtitles in video
- **Custom Quality** - Adjust bitrate (advanced)

## Tips for Better Videos

### For Short-Form Content
1. **Hook in first 3 seconds** - Capture attention immediately
2. **Keep it punchy** - Remove all dead air
3. **Add captions** - 85% of social media is watched muted
4. **Use trending audio** - Boost discoverability
5. **Strong CTA** - Tell viewers what to do next

### For Long-Form Content
1. **Chapters are essential** - Help viewers navigate
2. **Maintain audio quality** - Use noise reduction
3. **Consistent branding** - Use templates for intros/outros
4. **Thumbnail matters** - Use our thumbnail creator
5. **SEO optimization** - Add descriptions and tags

### General Tips
- Save frequently (or enable auto-save)
- Preview at different quality levels
- Test on mobile before publishing
- Keep project files organized
- Back up important projects

## Troubleshooting

### Video won't import
- Check file format is supported
- Ensure file isn't corrupted
- Try converting to MP4 first

### Preview is laggy
- Reduce preview quality
- Close other applications
- Check system requirements

### Export fails
- Ensure enough disk space
- Check file permissions
- Try different export preset

### Captions not generating
- Check audio is clear
- Ensure media has audio track
- Try shorter clips first

### App crashes
- Update to latest version
- Check system resources
- Report bug with crash log
